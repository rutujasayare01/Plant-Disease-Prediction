# 🌿 Plant Disease Prediction

An AI-based Plant Disease Prediction system that uses **Machine Learning and Deep Learning** to identify plant diseases from leaf images.

## 📌 Project Overview

Plant diseases can significantly affect crop health and productivity. This project uses a trained deep learning model to analyze plant leaf images and predict the corresponding disease.

The project includes a Python-based application interface for uploading or providing a plant leaf image and obtaining the predicted disease.

## 🚀 Features

- 🌱 Plant disease prediction from leaf images
- 🤖 Deep Learning-based image classification
- 🖥️ Python GUI application using Tkinter
- 🧠 TensorFlow/Keras model
- 📊 Trained using the PlantVillage dataset
- 📋 Disease information and prediction output

## 🛠️ Technologies Used

- Python
- TensorFlow / Keras
- Tkinter
- NumPy
- OpenCV
- PlantVillage Dataset
- Machine Learning / Deep Learning
